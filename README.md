# 基于深度学习的智能车辆变道轨迹自动生成测试系统

这是一个零额外依赖的 Python 测试系统，用于演示和回溯《基于深度学习的智能车辆变道轨迹自动生成方法及系统》计划书中的完整处理链路。

系统严格把计划书中未定义的内容作为输入项处理：预设轨迹生成网络的结构未在计划书中给出，因此本系统接收其输出点集 `T_raw`；当前控制周期的前瞻距离解析式未在计划书中给出，因此本系统将其作为测试输入。

## 运行

```powershell
python app.py
```

启动后浏览器会打开本地测试页面。页面包含登录、数据输入、数据处理、阈值重构、控制指令、反馈优化、测试报告等模块，界面结构参照演示视频的左侧导航和右侧表单/图表展示方式。

## 覆盖内容

- 获取预设轨迹生成网络输出的预选变道轨迹点集 `T_raw`
- 三点差分提取轨迹曲率序列 `K_raw`
- 离散微分提取曲率空间变化率序列 `Delta K`
- 曲率极性反转点检测：`kappa_i * kappa_{i+1} < 0`
- 以反转点为中心、预设空间范围内提取 `gamma_raw`
- 基于底盘载荷刚性分配参数和车速计算 `gamma_max`
- 当 `abs(gamma_raw) > gamma_max` 时执行局部曲率变化率钳位和空间位置迭代重构
- 基于目标曲率生成前轮转向角与 PWM 占空比
- 基于横向位移偏差和偏航角速度偏差计算反馈优化参数 `F_opt`
- 当 `F_opt < F_th` 时更新预设空间范围 `L_new`

## 目录

- `app.py`: 本地 Web 测试系统入口
- `src/lane_change_test_system/core.py`: 计划书公式和流程的核心实现
- `static/index.html`: 演示页面
- `docs/formula_traceability.md`: 计划书步骤、公式与代码函数的追溯关系
- `tests/test_core.py`: 核心公式和流程单元测试
