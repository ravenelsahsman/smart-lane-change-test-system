系统介绍

项目来源

本测试系统严格围绕项目书“基于深度学习的智能车辆变道轨迹自动生成方法及系统”构建，用于验证深度学习轨迹输出之后的曲率提取、曲率极性反转点识别、底盘物理阈值计算、局部曲率重构、控制指令生成和反馈优化闭环。

核心问题

连续 S 型变道时，轨迹曲率由左转切换为右转或由右转切换为左转，曲率反转点附近的曲率空间变化率过大，会使后轴动态载荷转移超过悬架阻尼极限，从而诱发后轮微观侧滑和横摆振荡。

测试对象

系统不擅自构造计划书未给出的神经网络结构，而是接收“预设轨迹生成网络输出”的预选变道轨迹点集 T_raw，并对该点集执行计划书中明确给出的三点差分、离散微分、阈值限幅、积分重构和控制映射。

验证目标

通过控制前轨迹与控制后目标轨迹的曲线、曲率、变化率、PWM 指令、反馈参数和动态小车运动演示，观察局部刚性限幅后轨迹反转是否更平缓，以及目标控制指令是否具备更高的执行稳定性。

提取模块从 T_raw 中提取几何曲率序列 K_raw 与曲率空间变化率序列 ΔK。
峰值提取模块按 κ_i*κ_{i+1}<0 锚定曲率反转点，并在预设空间范围内提取 γ_raw。
阈值获得模块利用车速 v 与底盘载荷刚性分配参数计算 γ_max。
重构模块当 |γ_raw| 超过 γ_max 时，对局部曲率空间变化率钳位并执行位置迭代重构。
控制指令模块将目标控制曲率映射为前轮转向角 δ 和 PWM 占空比。
反馈优化模块通过 F_opt 判断执行置信度，并按公式更新后续预设空间范围。
T_raw={(x_1,y_1),(x_2,y_2),...,(x_N,y_N)}
κ_i=(x_i' y_i'' - y_i' x_i'') / (x_i'^2 + y_i'^2)^(3/2)
κ_i'=(κ_{i+1}-κ_i)/Δs_i，曲率极性反转条件：κ_i * κ_{i+1} < 0
γ_max=(K_damp*t_w)/(m*h_g*D_r*v^3)
κ_safe(s)=κ_safe(0)+∫_0^s κ_rate(l)dl，θ(s)=θ_0+∫_0^s κ_safe(l)dl
δ=arctan(L*κ)，Duty=K_pwm*δ+Duty_center
F_opt=exp(-λ1*e_y^2-λ2*e_ω^2)，L_new=min(L_max,L_old+ρ*(F_th-F_opt))
